# 2026-08-08 移除独立链上模块

## 场景

用户决定安全技能路由包不再维护独立 Crypto/Web3/链上产品线，并要求本地与远端同时清理。

## 可复用经验

1. 先同时检查 Git 已跟踪内容、ignored 目录和 stash；只扫 `git ls-files` 会漏掉本地私有扩展。
2. 删除混合 stash 前先按文件重建一份最小 stash，保留无关资料，再删除含目标内容的旧 stash。
3. 产品模块删除后要同步清理 `.gitignore`、工具探测、ghost 测试和文档示例，否则仍会形成隐性产品边界。
4. 区分“独立产品线”和“基础技术能力”：删除链上模块不应误删逆向任务仍需的 AES/RSA/编码识别。
5. 递归删除必须先解析绝对路径，并用 `git clean -ndX` 预演 ignored 目录范围。
6. 严格 case 审查可暴露跨平台解析缺陷：资产块的结束条件必须只匹配顶层字段，不能把缩进的 `D:\\...` 当成字段名。

## 结果

- 本地两个隐藏扩展目录已删除。
- 链上日志已从 stash 清除，无关支付日志保留。
- 主线链上路径及内容引用清零。
- 以完整回归和残留关键词扫描作为推送门禁。
